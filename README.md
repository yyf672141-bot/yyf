## 云端同步

1. 新建一个独立的 GitHub **私有**仓库，例如 `cpa-lab-data`。
2. 在 GitHub 创建 Fine-grained Personal Access Token，只选择该数据仓库，授予 Contents: Read and write。
3. 在网站“配置云端同步”填写数据仓库和 Token。连接时合并成绩、错题、导入题卷和未完成考试；考试中每 30 秒及保存退出时同步。
4. 另一台设备连接同一数据仓库，再点“立即同步”。同一份考试请只在一个设备作答，切换前保存退出。

Token 只存当前浏览器会话，直接发送给 GitHub。网站拒绝把个人训练数据同步到公开仓库；本仓库只托管网页。

## AI 精批

在网站“配置 AI”中填写自己的 DeepSeek API Key。浏览器直接调用官方 API；Key 仅存当前浏览器会话，不进入 GitHub 训练记录或备份。调用消耗用户自己的 API 额度。

- CPA 主观题按参考答案、得分点逐点评分。
- 银行、基金已作答错题提供误区、选项和记忆提示；客观题分数保持标准答案判分。
- 可在交卷时自动启动，或从已有报告单独启动；分批保存反馈，中断后可继续未完成题目。

网络失败时保留本机副本与原有评分。所有评分仅供练习。

## 2026-10-19 错题复习与备份优化

错题按科目及题干/材料/题型合并，相同题目在重组卷出现时不重复统计。默认只展示已作答错题，未作答题可单独勾选；首页待重练数量排除已掌握题及重复记录。错题本支持科目、到期/复习中/已掌握状态、错误原因、关键词筛选及分页，同科筛选结果可组10/20题批量重练。解析默认收起，保留逐题来源。

批量重练保留原题ID，交卷后逐题更新复习计划：做对延长至3天起，做错次日复习；未作答不新建错题。重做错题的草稿包含复习目标，刷新续答仍能更新计划。已掌握题在新的练习中再次答错会恢复复习。首页增加到期错题入口。

导出升级为v3完整训练备份，包含成绩、复习、用户导入题卷和未完成试卷，不包含连接凭证。导入兼容旧版，按ID及更新时间合并，不再整体覆盖本机记录；保留较新的本机记录及完成草稿的删除时间。格式错误不写入；存储写入失败尝试回滚已改动键。空历史页面也可导入备份。

考试计时改为按实际经过时间扣减，避免后台定时器变慢造成漏计；纯客观题报告显示原始参考答案得分，不再显示四舍五入的估分区间。现有云端与AI功能沿用原流程；相关自动检查共36项通过，另验证批量重练、刷新续答与交卷页面流程。
